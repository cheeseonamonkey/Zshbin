A standalone pastebin in development, designed for optional public sharing, client-side encryption, expiration, and a small MCP interface.

View repository ↗ Read roadmap
$ uv tool install git+https://github.com/cheeseonamonkey/Zshbin.git
$ gh auth login
$ zshbin auth
$ zshbin notes.txt --public

Encryption is not implemented yet. Current uploads are explicit public plaintext only. Do not upload secrets.

  • CLI firstGitHub identity, shared storage core.
  • Encrypted sharingPer-file keys, authenticated encryption. Planned.
  • Minimal MCPFour planned operations: list, push, pull, delete.
